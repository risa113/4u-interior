# 4U Interior Decorator Atelier Website

Production website for **4U Interior Decorator**, crafted based on the approved STITCH UI design (*Atelier Verte Edition*).

## Project Overview

- **Business**: 4U Interior Decorator
- **Location**: New No.26, Swami Nellaiappar High Rd, Tirunelveli, Tamil Nadu 627001
- **Contact**: 081227 09961
- **Focus**: Luxury Residential Interiors, Commercial Design, Modular Kitchens, and Precision Gypsum False Ceiling Execution.

## Tech Stack

- **React 18** + **Vite**
- **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Google Fonts** (Bodoni Moda, Plus Jakarta Sans)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```
